## Objective

The objective of this lab is to identify and document the requirements of a Community Solar Credit Allocation Manager system and represent its functionality using a Use Case Diagram and Use Case Flow.

## Contents

This folder contains:

### Use Case Diagram

Shows the actors and their interactions with the Community Solar Credit Allocation Manager system.

### Requirements

Contains the functional and non-functional requirements of the system.

### Use Case Flow

Describes the steps involved in allocating solar credits.
